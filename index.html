FAQ

Frequently asked
questions.

Everything you need to know about NightOrbit CodeForge.

Is my code ever uploaded to your servers?
No. Every tool runs entirely in your browser using client-side JavaScript. Your code never leaves your device. We only store your encrypted key metadata (which we cannot decrypt) in Firebase Realtime Database. Even if we wanted to view your code, we couldn't — it never touches our infrastructure.
What happens if I forget my password?
Your password is the only way to decrypt your key. We follow strict zero-knowledge architecture — we cannot recover it, reset it, or bypass it. You'll need to Delete Key and create a new one, but old encrypted data will remain locked forever. This is by design — it's what makes the system truly secure.
How does Console Shield differ from Code Encrypt?
Code Encrypt makes your source unreadable at rest — it protects the file itself. Console Shield protects your code at runtime — it blocks console injection attempts, XSS, DevTools access (F12, Ctrl+Shift+I, right-click), and script-based attacks while your code is executing. Use both together for full protection: encrypted at rest, shielded at runtime.
Can I use these tools commercially?
Yes. All tools are available for commercial use. The protections we generate are royalty-free and can be deployed in commercial products without restriction. You don't need to credit NightOrbit, and we don't claim any ownership over your original code.
Which browsers are supported?
Chrome, Edge, Firefox, Safari, and Brave — all modern browsers with Web Crypto API support. Mobile browsers (iOS Safari, Android Chrome) are fully supported. We recommend the latest version of your browser for the fastest cryptographic operations.
How strong is AES-256 encryption really?
AES-256 is the same standard used by the US National Security Agency (NSA) for TOP SECRET information. Brute-forcing a 256-bit key would require more energy than the sun will produce in its lifetime. With our additional 600,000 PBKDF2 iterations on top, password-guessing attacks become computationally infeasible even with nation-state resources.
What is zero-knowledge architecture?
Zero-knowledge means we architect our system so that we literally cannot access your data — even if compelled by a court order, a hacker breach, or an insider threat. Your encryption key is never transmitted to our servers in plaintext, and your password is never stored anywhere. Only you can decrypt your own data.
Does Console Shield slow down my website?
No. Console Shield adds less than 2 milliseconds of overhead on modern browsers. The runtime checks are optimized and use passive event listeners where possible. In benchmarks, a typical page sees a TTI (Time to Interactive) increase of under 5ms — imperceptible to end users.
What if I lose my decryptor file or key file?
Both files are required for decryption. If you lose either one, your encrypted data is permanently locked — no recovery is possible. We strongly recommend storing multiple backups: one on your local machine, one on an external drive, and one in a secure password manager or encrypted cloud storage.
Can encrypted code be decrypted by someone else?
Only if they have both the decryptor file AND your password. Without the password, the decryptor is useless. Without the decryptor, the password is useless. This two-factor approach ensures that even if one file leaks, your code remains protected.
Is there an API I can integrate into CI/CD?
Yes — Professional and Enterprise plans include API access. You can trigger encryption, obfuscation, and compression jobs directly from your build pipeline. Documentation is available in the Developer Portal. Rate limits: 100 req/min (Pro), unlimited (Enterprise).
How do I get support?
Free users get community support through our GitHub Discussions. Professional users get email support with a 24-hour response SLA. Enterprise customers get a dedicated Slack channel with a 1-hour critical response SLA and a named technical account manager.
